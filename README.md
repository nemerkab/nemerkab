## Bryce Kaiser

**Founder at [Centered](https://centered.team)** — a venture studio in Michigan that co-founds
companies on one rule: *Sell First, Build Later.*

I've spent the last decade-plus building inside Michigan startups. These days I split my time
between getting products in front of paying customers before a line of code is written, and
building the software — increasingly the *agents* — that keeps those products healthy once
they're live.

### How I work

- **Sell first.** Demand is the only validation that costs nothing to be wrong about. Everything else is a guess with a burn rate.
- **Ship small, ship often.** Idea to something a customer can actually touch, in under a week.
- **Automate the maintenance.** Shipping features is the cheap part; keeping them working is the expensive part. That's where I point agents.
